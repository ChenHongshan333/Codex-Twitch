    Bring the battle into OBS

    1. For physical play, select Camera tracker, open Camera setup and calibrate a bright coloured body marker. Keep both tracker windows visible.
    2. Add Coral OBS URL ↗ and Violet OBS URL ↗ as 960 × 540 Browser Sources over their matching camera crops and mirror settings. If OBS holds the webcam, use OBS Virtual Camera without the overlay in its feed.
    3. In OBS, Start Streaming sends the composed picture to Twitch; Start Recording saves a video. Chat still comes from the real Twitch chat rooms.
    4. Messages have equal 128 × 28 hitboxes. Five health; 1.5-second grace after a hit. Tracking loss pauses the round.

    This prototype runs on one machine. Remote streamer transport and external VTuber avatar adapters remain pending. The rehearsal figure is a test target, not a live video or an external avatar.
