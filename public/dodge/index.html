Quick setup & fair play
  1. For a quick rehearsal select keyboard markers for both sides, then Start. Focus an arena and use WASD / arrow keys, or drag its marker.
  2. For physical play, select Camera tracker and calibrate a bright coloured sticker on the body point you want to dodge with. Keep both tracker tabs visible. Losing either marker pauses the round.
  3. Add each OBS overlay URL as a Browser Source at 960 × 540, over the matching camera crop with the same mirroring. The marker must line up. If OBS holds the webcam, use its Virtual Camera as tracker input, excluding the overlay from that feed.
  4. All messages have a 128 × 28 hitbox, a warning interval and a 14-unit player marker. Paid support has capped weight. Five health; 1.5-second grace after a hit.
  5. This local prototype serves one machine. Remote streamer transport and specific VTuber avatar adapters are not implemented yet. Keyboard mode moves a test marker only.
